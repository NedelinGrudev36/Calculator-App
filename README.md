# 🧮 JavaScript Calculator

A simple calculator built with HTML, CSS and JavaScript.

## 🚀 Features

- Basic operations: +, -, *, %
- Clear button (C)
- Responsive layout using CSS Grid
- Real-time calculation without page reload

## 🛠 Technologies Used

- HTML
- CSS (Grid Layout)
- JavaScript (DOM manipulation & events)

## ⚙ How It Works

- All buttons are selected using `querySelectorAll`
- A click event listener is added to each button
- The display updates dynamically
- `eval()` is used to calculate the result when "=" is pressed
